# 🔌 PC Maintenance - Gemini AI Server

Backend proxy service that handles API calls to Google Gemini AI for the PC Maintenance web platform. It securely processes user queries regarding hardware troubleshooting, error codes, and component compatibility.

## ✨ Features
* 🔒 **Secure API Integration:** Manages Google Gemini API keys securely without exposing them to the client.
* 🤖 **Prompt & Context Management:** Structures queries and context to optimize Gemini AI responses for hardware diagnostics.
* ⚡ **Lightweight API Service:** Fast handling of chat requests and error query endpoints.
